# 🚜 Transport Operations Analytics (Excel + Power Query)

## 📖 Overview

This project demonstrates the process of transforming raw operational data into analytical reports using **Microsoft Excel** and **Power Query**.

The project was focused on preparing, cleaning, and analyzing transport operation data to identify performance indicators, working time patterns, and downtime factors.

The original dataset was provided as part of a recruitment test assignment and is not included in this repository due to data confidentiality considerations.

---

## 🎯 Objectives

- Clean and prepare raw operational data
- Transform date and time fields for analysis
- Create shift classification
- Calculate operational indicators
- Analyze equipment working time
- Identify downtime patterns
- Build analytical reports and visualizations

---

## 🛠 Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Excel Formulas

---

## 📊 Project Workflow

### 1. Data Preparation

- Imported raw operational data
- Cleaned and structured source information
- Processed missing values and data types
- Prepared data for further analysis

### 2. Data Transformation

- Converted date and time fields
- Created calculated columns
- Added shift classification logic
- Prepared analytical tables

### 3. Data Analysis

Created reports for:

- Equipment working time analysis
- First entry and last exit monitoring
- Shift-based performance analysis
- Downtime reason analysis
- Operational efficiency evaluation
