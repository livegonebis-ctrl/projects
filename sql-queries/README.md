# 💳 Banking Transaction Analytics (SQL)

## 📌 Project overview

This project demonstrates SQL analysis of banking transactions using PostgreSQL.

The goal of the project is to practice writing analytical SQL queries commonly used by Data Analysts.

---

## 🛠 Tools

- PostgreSQL
- DBeaver
- SQL

---

## 📂 Dataset

The dataset contains information about:

- Transaction ID
- Origin Account
- Destination Account
- Transaction Type
- Transaction Amount
- Transaction Date
- Branch ID

Rows: 50,000
